# Scottrix

Free, privacy-first web tools — all client-side, no data collection, no login required.

| Site | URL | Description |

| **DevTools** | [scottrix.github.io/devtools](https://scottrix.github.io/devtools/) | 30+ online developer utilities |

| **GCSE Revise** | [scottrix.github.io/gcserevise](https://scottrix.github.io/gcserevise/) | Free GCSE revision notes for 37 subjects |

## Principles

- **100% client-side** — no server processing, no API calls, your data stays in your browser
- **Privacy-first** — no cookies, no tracking, no analytics, no login
- **Free forever** — no paywalls, no accounts, no limits
- **Open source** — all code is publicly available on GitHub

## Tech Stack

- Static HTML/CSS/JS hosted on GitHub Pages
- CSS custom properties for theming (dark/light mode)
- Responsive design (mobile-first)
- Search Engine Optimization (schema.org, Open Graph, Twitter Cards)
